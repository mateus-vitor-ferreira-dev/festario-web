# Política de segurança

## Como reportar uma vulnerabilidade

Reporte de forma privada pelo GitHub:

1. Abra a aba **Security** deste repositório.
2. Clique em **Report a vulnerability**.
3. Descreva o problema, os passos para reproduzir, o impacto que você enxerga e, se tiver, uma sugestão de correção.

Não use issues, pull requests ou discussões públicas para isso.

## O que fazer

- Teste só com contas suas e com o mínimo de dados necessário para provar o problema.
- Pare assim que confirmar a falha e reporte logo.
- Mantenha o assunto em sigilo até a correção ser publicada.

## O que não fazer

- Não acesse, altere nem apague dados de outras pessoas ou de outros salões.
- Não faça testes de negação de serviço, spam ou engenharia social.
- Não use força bruta contra login ou outros endpoints.
- Não divulgue a falha antes da correção.

## Prazo de resposta

Respondemos em até **5 dias úteis** com a confirmação do recebimento e os próximos passos. Depois, avisamos quando a correção for publicada.

## Escopo

Vale para este repositório e para o app em https://app.festario.com.br. Problemas da API podem ser reportados aqui também: encaminhamos para a equipe responsável.
